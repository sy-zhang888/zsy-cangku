Agent（智能体）

给它一个目标，它会自己想办法、动手做、做完再检查。

学完你能做什么

  • 用一句话说清 Agent 和普通聊天 AI 的区别
  • 画出 Agent 的四个零件，并讲出每个零件干什么活
  • 判断一件事该交给 Agent 做，还是自己一步步来更划算

先问三个问题

1. 为什么我让 AI "帮我订机票"，它只会回我一段订票攻略？
2. Agent 到底比普通的 AI 聊天多装了什么东西？
3. 既然 Agent 能自己干活，为什么还需要人在旁边看着？

它像什么：答题机 vs 办事员

普通的 AI 聊天像一台答题机：你问一句，它答一句，答完就结束。它不会主动去查天气，也不会帮你把文件存好。

Agent 像一个出门办事的小助手。你只说一句"把这封信送到外婆家"，他会自己查地图、骑车出发、发现前面修路就绕道、到了还要你签字确认——中间这些步骤，不用你一件件吩咐。

这个比喻在哪里不准：真实的办事员有眼睛有腿，能真的看见路口在施工。Agent 没有身体，它的"眼睛"是搜索和读文件，"手"是软件工具，它看到的一切最终都变成了文字。所以它能"看"到的世界，比人的小得多。

它怎么工作：四个零件 + 一个圈

Anthropic 的工程师把这类系统叫做 agentic system（智能体系统），并指出它的基础构件是"被增强过的大模型"——也就是一个大脑，外挂了检索、工具、记忆三种能力。

四个零件分别干什么

零件具体干什么活
大脑读记事本里已有的内容，判断"现在该做哪一步"，以及"这件事算不算做完了"
手（工具）真正在外面产生动作：上网搜、打开文件、运行一段代码、调用一个接口
记事本（上下文）把每一步的想法和工具返回的结果按顺序记下来，下一步要读它
循环想 → 做 → 看 → 再想，直到大脑判断目标达成

用在哪儿：周五班级读书会的发言稿

你给 Agent 一个目标："围绕《城南旧事》准备一段 3 分钟的发言稿。"它可能会这样干：

  1. 想：先要知道这本书讲了什么、作者是谁、3 分钟大概多少字
  2. 做：打开你电脑上放书摘的文件夹，把内容读出来
  3. 做：上网查作者林海音的生平和写作背景
  4. 做：算一算 3 分钟 ≈ 600 字，据此列出发言提纲
  5. 看：写完初稿后自己数了数字数，发现超了 200 字
  6. 改：删掉两段例子，重新数一遍，确认合适后才交给你
注意第 5 步：Agent 会自己检查、自己返工，这正是它和"一次性生成一段文字"最大的不同。不过它也可能漏掉你最想讲的那段——所以最后还是要你自己读一遍。

容易搞混的四件事

名字谁决定下一步适合干什么
Agent大模型自己决定事先说不清步骤的开放任务
工作流 Workflow人写好的固定流程步骤能提前列清楚、要求稳定的任务
普通 AI 聊天你一句它一句问答、改写、解释概念
工具 Tool它自己不决定任何事被 Agent 调用，是"手"不是"人"

使用边界（它做不到什么）

  • 会绕圈子：可能在一个步骤上反复尝试，一直转不出来
  • 完成率不是 100%：Anthropic 的教程明确指出，Agent 比工作流的成功率更低，也更难测试和评测
  • 记事本会满：步骤太多时，前面的内容会被挤出去，它就开始"忘事"（详见《大模型的上下文》）
  • 越用越贵：每一轮循环都要重新读一遍记事本，步骤越多花的钱和时间越多
工程师的经验是：能不用 Agent 就先不用。步骤能提前写清楚的，就写成固定流程，又便宜又稳。

自测三题

1. 小明说"我让 AI 写一首诗，它写得很好，所以它一定是 Agent"。这句话哪里不对？
看答案

写诗只是一问一答，AI 没有自己拆步骤、也没有调用任何工具去确认事实，它还是"答题机"。判断是不是 Agent，要看它有没有自己决定下一步并真的动手。

2. 如果拿掉"记事本（上下文）"，Agent 会发生什么？
看答案

它会失忆。每一轮都不知道上一步做了什么、工具返回了什么，于是会在同一步上原地打转，或者反复做已经做过的动作。

3. 什么情况下你不该用 Agent？
看答案

当任务的步骤能提前一步不差地写出来时。这时用固定流程更稳定、更便宜、也更容易检查对错。

    https://www.anthropic.com/engineering/building-effective-agents

  2. Anthropic Claude Academy，《Workflows vs agents》

  3. Anthropic，《Equipping agents for the real world with Agent Skills》（2025）
    https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
